# Simulator readiness before the field release

On branch `main` at `c41a406`, Phase 10A/E code, dataset documentation and research files were already uncommitted. Inspection covered the grid engine, disaster registry, symbolic sensor, drone cycle, router, command journal, evaluator, parallel environment, experiment runners, backend scenario loader, manifests and reviewer CLI. The external pilot still held 510 pending examples across 13 episodes, 50 queued forms and 6,385,696 bytes. It supplied one controlled contradiction, two duplicate/relay presentations and one controlled false alarm.

| Prior behavior | Field release response or remaining limit |
|---|---|
| Cyclone reused flood ground/hazard defaults. Landslide reused earthquake defaults. One scripted tile change could distinguish fixture names without changing observation conditions. | Six versioned fixtures combine different event schedules, occlusion windows, viewing ranges, radio faults, civilian behavior and terrain. |
| No dedicated missing-person mission. Random civilian placement used the whole free grid. | A trail search samples one moving civilian from a configured initial region. Sensor noise and scheduled visibility loss produce incomplete sightings. |
| Uniform nominal modality set. Symbolic readout was either the precise tile label or a sighting. | Window outages, alternate-agent capability loss, indistinct terrain and uncalibrated sighting scores affect operational readings. |
| Legacy evidence IDs could recur for different seeds at the same agent/tick/modality/reading index. | Version 2 scopes sensor identity by scenario, seed, fleet and difficulty. Version 1 retains its historical semantics. |
| Basic CLI/parallel actions can step the world without either agent. Coordination experiments use drones and transport without central assessment. | The dataset uses the integrated fleet with one command consumer per episode. Independent replay compares each observation envelope against the standard command journal. |
| The simulator models neither disaster physics nor raw synchronized media. Sparse conflicts and recurring symbolic patterns limit generalization. | Measure overlap, expose the actual capture modalities and preserve weak-label provenance. Real calibration and independent annotation remain outstanding. |

**Public-source decision.** HERIDAL, SARD, FloodNet, RescueNet, FLAME, WiSARD and ESC-50 had no approved, development-partition calibration statistics in the acquisition audit. Smoke Detection IoT, UCI Air Quality and USGS Water Data had local whole-source measurements, with unresolved governance and no validated development partition. Stationary samples and period summaries do not establish onboard observations. No quantities from these ten sources were used to set simulator parameters. CrisisMMD and HumAID retain their distinct public context objectives, splits and review holds. NASA POWER and CrisisNLP were outside this release.
