# Dataset collection readiness specification (Phase 10 preparation)

This is a specification only. **No dataset was acquired, scraped, annotated or generated in
Phase 9.** Only the existing minimal test fixtures were used to verify interfaces.

## Datasets the later phases need

| Consumer | Purpose | Kind | Notes |
|---|---|---|---|
| Model 1 perception (Phase 11) | detect possible people and hazards per modality | real-world public research datasets (aerial RGB, thermal; possibly audio, text) | must match the `Evidence.modality` vocabulary |
| Model 1 fusion and uncertainty | combine modalities, handle missing ones | paired or co-registered multimodal samples | missing modalities must be represented, not imputed silently |
| Model 2 assessment (later) | incident grouping, urgency, recommendation support | synthetic simulation logs + expert-defined labels | labels are evaluation-only unless defined as training targets |
| MARL (Phase 12) | coordination policies | synthetic simulator episodes | generated by the simulator; no real data |

Kinds of data must stay separate in storage and in every manifest: **real-world public research
data**, **synthetic simulation data**, **evaluation-only labels** (ground truth), and
**operational observations** (what agents reported).

## Required metadata per sample

| Field | Requirement |
|---|---|
| Provenance | source dataset name, version, URL or DOI, retrieval date, original identifier |
| Licence | exact licence and usage restrictions; research-only data never mixed into redistributable sets |
| Scenario metadata | disaster type, environment, time of day, weather, sensor platform |
| Source identity | sensor or agent identifier (for synthetic data: agent key and mission) |
| Timestamps | capture time (UTC or simulation ms, stated), never inferred silently |
| Coordinates | coordinate reference system stated; local grid cells (`swarm-aid:grid`) are not GPS; uncertainty recorded; missing location stays missing |
| Modality | one of `image`, `video`, `thermal`, `text`, `gps`, `imu`, `environment`, `peer` (or a versioned extension) |
| Missing modalities | explicit list per sample |
| Labels | label schema version, annotator or source, label confidence/uncertainty, adjudication status |
| Data quality | resolution, corruption checks, duplicates, near-duplicates, class balance report |
| Versioning | content hash per file, dataset version, manifest digest |

## Label definitions to agree before collection

- Person present / possible person / no person (per region or per frame), with an explicit
  "uncertain" class.
- Hazard classes aligned with simulator hazards (`water`, `fire`, `debris`, plus restricted or
  blocked terrain) or a documented mapping.
- Evaluation-only labels (for example true person locations in synthetic episodes) are never
  used as model inputs.

## Privacy, ethics and licensing

- Prefer public datasets with explicit research licences; record licence text with the data.
- Imagery of real people: check consent and licence terms; never collect new imagery of private
  individuals; blur or exclude identifiable faces unless the licence and purpose allow it.
- Keep imagery and private artifacts out of logs and version control (AGENTS.md); store under a
  git-ignored data root with a manifest committed instead.

## Splits and leakage prevention

- Train/validation/test splits are fixed and versioned before training.
- Split **by scenario or location and by source sequence**, not by frame, so near-identical
  frames never cross splits.
- Synthetic episodes: split by scenario and seed ranges; the evaluation seeds used in the
  Phase 9 matrix (42–46) should be reserved for evaluation.
- No evaluator ground truth, test labels or test-scenario statistics in training features,
  normalisation statistics or model selection.

## Storage conventions (proposed)

```text
datasets/                      # data root; contents git-ignored (only .gitkeep tracked)
  <name>/<version>/
    manifest.json              # provenance, licence, hashes, splits, label schema version
    raw/  processed/  labels/  splits/
```

The repository's `datasets/` folder holds only `.gitkeep` (everything else is git-ignored); Phase 9 added nothing to it.
