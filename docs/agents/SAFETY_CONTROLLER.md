# SAFETY CONTROLLER

authorize evaluates the unfused measured frame, authenticated lease, simulated link state, public grid extent, restricted cells, current lifecycle and operator override. Movement requires an unexpired matching task, current position and explicit movement configuration. End instructions require authority. Phase 2 checks collisions, energy and physical feasibility at commit. A revision-bound pause holds and clears the lease. Resume requires a new assignment. All model calls run inside a fail-closed boundary.
