# Model 1 perception and fusion

`perceive(SensorFrame) -> tuple[Finding,...]` receives one agent's ID, mission-relative tick, own evidence tuple, nullable cell and measured battery fraction. A Finding wraps an Observation with stable ID, nullable cell, observed time, confidence and nonempty evidence. Environment and hazard findings require a label; possible_human requires a null label. Fusion consumes the frame and findings and returns a LocalView. Current MockPerception also uses private symbolic readings. The runtime defines no pixel tensor, patch size, audio rate or model input dimensions.

External sensor datasets must supply physical bytes, capture provenance, source labels and a way to group correlated scenes. The supported Evidence modalities are image, video, thermal, text, gps, imu, environment and peer. The research manifest can inventory audio separately. An audio provider would require a versioned operational contract. Quality or absence of any modality must remain observable. With a missing stream, evaluate the available subset or abstain and retain the missing list. Never generate a positive finding from a missing input.

| Task and input | Required target and future output | Negatives and missing input | Quality, metric and limitation |
|---|---|---|---|
| RGB aerial human detection, image/video frames | Source person boxes, visibility, reviewed empty frames. Map supported detections to possible_human with original evidence. | Empty terrain and person-shaped debris; abstain on missing RGB. | Preserve native resolution, flight grouping and person pixel size. Box AP, recall by size and false alarms per empty frame; person presence alone cannot establish rescue need. |
| Environmental scene classification, RGB | Reviewed scene or tile categories and unknown class; emit environment + mapped feature. | Other terrain, shadows and mixed scenes; mark absent imagery. | Balance viewpoint and lighting. Macro F1 and confusion by site; a frame may contain multiple surfaces. |
| Thermal human detection, thermal frames | Thermal-space person boxes and source calibration/encoding; emit possible_human. | Hot roofs, animals, engines and empty night scenes; record absent thermal. | Record bit depth, sensor range and gain where known. Day/night AP and false alarms; intensity alone cannot establish identity. |
| Fire/smoke, aerial RGB or thermal | Separate fire and smoke image tags for classification or masks for segmentation; map supported observations to approved hazard/feature vocabulary. | Fog, cloud, dust and warm surfaces; score each available modality. | Record occlusion and annotation granularity. Per-class precision/recall for tags, IoU for masks. A smoke-only report cannot establish fire extent. |
| Flood observation, aerial RGB | Water/flooded-area masks and reviewed land/water mapping; summarize supported flood evidence. | Normal waterways, dark pavement; missing frame is unknown. | Audit boundaries and event diversity. Per-class IoU and false flooded area; visible water alone cannot establish depth. |
| Structural damage, overhead imagery | Damage masks/polygons or ordinal source labels with assessment scale; summarize observed damage. | Intact buildings, shadows and pre-existing damage; flag missing pre-event view. | Preserve pre/post registration and building footprint. Macro F1 or IoU by event; satellite-to-UAV scale transfer needs evaluation. |
| Audio event classification, physical clips | Clip tags or timed intervals with source ontology; future event score only. | Wind, motors, unrelated voices and silence; mark absent audio explicitly. | Document sample rate, clipping and recording origin. Macro AP and class recall. Current Evidence has no audio variant. |
| Environmental sensor interpretation, GPS/IMU/environment records | Unit, sensor ID, timebase, validity flags, known event/window label; derive scoped environmental observations where mapping exists. | Normal readings, drift, dropouts; missing measurement stays unknown. | Check calibration and synchronization. Macro F1 for states or MAE for measured quantities; grid coordinates cannot substitute for GPS. |
| Multimodal fusion, synchronized physical RGB/thermal or timestamped streams | Explicit pair membership, alignment method, offsets and shared labels; return evidence-linked LocalView. | Misleading single-modality cues and true negatives; assess every observed subset. | Validate registration, clock tolerances and split groups. Compare fused vs unimodal recall and false alarms on the same held-out scenes. |
| Uncertainty estimation, evidence plus independent held-out labels | Source ambiguity, confidence and adjudication; evaluate calibrated score/abstention offline. | Hard negatives and ambiguous/missing modalities retained. | Measure Brier score and risk versus coverage by source; current confidence has no calibrated probability guarantee. |

**Label decisions still open.** For review, distinguish visible person, possible person, reviewed absence, and uncertain/unobservable. An unlabeled region has unknown status. Preserve source labels for fire, smoke, water, debris, blocked access and structural condition. Version a reviewed mapping per release, including ignore classes, thresholds and annotation agreement, before emitting operational labels. Distress, injury and rescue need require separate evidence and human authority.
