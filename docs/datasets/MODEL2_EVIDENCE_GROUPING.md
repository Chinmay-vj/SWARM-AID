# Evidence grouping and lineage

For each admitted or rejected finding in the command journal, capture the authenticated sender/session and actual envelope ID. Content normalization uses the existing Finding and ReportedFinding types. Hashes identify the complete journal and normalized receipt ledger per episode. Validate the original observation, sender, session, send/receipt time and message ID against the journal. The operational context is built before the current receipt is entered into the dataset collector’s admission index.

A neighbor must have been admitted earlier, share a non-null reported cell, and be younger than the command freshness window at the current processing time (1,500 ms here). Earlier processing order resolves simultaneous ticks. Empty location has no spatial group. Adjacency of grid cells, event names alone and unrelated posts provide no association. Distinguish these candidate-context sets from actual command associations: a baseline incident uses the command’s kind/label/cell rule, explicit incident ID/revision and cited reports. Retain those separately in targets.

Identity conflict has precedence. An observation ID carrying altered content conflicts; co-timed same-kind reports with different labels in one cell also conflict under this heuristic. Reusing an observation ID or evidence ID indicates duplication. Otherwise, same kind, same label and cell with disjoint originating agent sets is a corroboration candidate. Other nonempty contexts are related; empty context is single. Distinct relay identities do not establish independence. Temporal coincidence and distinct origins still permit shared sensor error or two different people in one cell.

The release has 509 unique episode-scoped sets of report IDs, including controlled cases, and 70 distinct episode-scoped baseline incidents associated with exported updates. Neither is a count of real people. Agency, freshness and evidence content should be inspected before interpreting an individual edge. [Implementation](../../evaluation/data/model2_collect.py)
