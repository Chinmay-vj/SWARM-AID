# Model 2 command dataset v1.0

The observation unit is one command-side presentation of a symbolic finding, with the previously admitted context available at that decision. The release is for offline civilian decision-support research. Model 2 consumes authenticated reports and can propose incident assessments, review priority and evidence-linked recommendations. A physical rescue outcome, confirmed need or independently measured urgency is unavailable.

| Task | Input and output | Current supervision |
|---|---|---|
| Classification | Finding kind and optional feature/hazard label; incident category; review urgency | Finding kind/label originate with the mock agent. Routine is a downstream weak mapping. The other populated categories and priority levels come from the command baseline. Independent report relevance and evidence sufficiency require review. |
| Aggregation | As-of report group → duplicate, conflicting, corroborating, related or single | Explicit deterministic rules. Distinct origins supply a proxy for independence. |
| Structured generation | Incident, known uncertainty and report lineage → allowed review request with expiry and cited evidence | Actual baseline proposals are retained. No free-text rescue directives or physical commands. |

**Records.** `model2_records.Input` contains schema/source ID, episode and unchanged mission IDs, scenario, seed, split, fleet size, sample and parent IDs, capture variant, disabled scenario modalities, communication status, typed receipt and ordered context. Each receipt contains the unchanged ReportedFinding, sender principal, session, send and receipt milliseconds. Finding retains observation ID, cell, observed time, source confidence and original Evidence tuple with IDs, origins, captured times, modality and symbolic artifact keys. Provider identifiers and code digests live in release metadata. No independent provider package version is available.

**Feature boundary.** Use features.jsonl, with opaque sample ID for joins only. Model inputs are the focal receipt, earlier context and receipt age. Source/split/variant/seed metadata stay in inputs.jsonl. The age clock is receipt time minus observed time. Configured disabled modalities indicate scenario capabilities; they do not imply the agent measured every other modality at every tick. Source reports already contain rule-generated finding labels and confidence. Mask the field being predicted and deterministic encodings of it when evaluating reconstruction of a source label.

**Targets.** targets.jsonl stores provenance, status, revision, relationship, optional assessment, baseline Incident and Recommendation, urgency, relevant evidence links, uncertainty, missing information and review requirement. Null means unavailable or unannotated. Only three requests are legal: inspect_evidence, request_observation and review_rescue_need. Confirmed rescue need is prohibited in this pilot. The separate evaluator.json holds one known controlled scenario reference. Public annotations, when inspected, belong to their own source namespace.
