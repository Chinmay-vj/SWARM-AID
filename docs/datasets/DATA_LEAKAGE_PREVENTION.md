# Split and evaluator boundaries

1. Collect the complete proposed comparison index before assigning partitions. Preserve official folds where compatible. If an official split separates related captures, retain its original assignment in metadata and document an alternate grouped research split or exclude the affected samples.
2. Assign canonical group IDs to original sequence, recording, flight, coarse location, disaster event, incident and RGB/thermal pair where applicable. Use source-qualified IDs for local identifiers. Use the same global ID when sites/events recur across releases. Real samples require sequence or location. Attach every relevant grouping key, including a parent capture for adjacent frames, crops and conversions.
3. Assign whole connected groups to one split. Check every manifest together. Same SHA-256 across splits, shared source item, sequence, location, event, pair, incident or mission, or same scenario-seed across splits fails validation. Same-split duplicate content may represent derived views and requires count/review before fitting. Use a shared event group or separate scenario-family holdout for tests of unseen disasters. ID and hash checks cannot detect undisclosed group membership or re-encodings.
4. Reserve seeds 42–46 inclusive for test/evaluation in **every** synthetic release. Model selection and normalization use only eligible training/development groups. Keep seed, configuration and split digests with every comparison; changed split policy creates a new manifest revision.
5. Separate operational, training-target and evaluator manifests. Target files are prohibited as operational input when validating the collection. Export only an explicit operational feature allowlist, with per-agent and as-of-tick access. Keep evaluator directories inaccessible to operational loaders. Check joined records for later outcomes, hidden truth IDs, private memory and test-set statistics. Validate offline; the research package has no import path into the running system by design.

Repeated reports and packet receipts count separately as transport events. Independence derives from original evidence, never number of deliveries. No split algorithm can infer a missing flight identifier reliably from adjacent filenames.
