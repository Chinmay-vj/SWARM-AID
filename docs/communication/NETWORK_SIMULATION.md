# NETWORK SIMULATION

Scenario delay and jitter count ticks. Seeded loss and duplicate probabilities apply per recipient. Jitter varies delivery order. Peer recognition uses Manhattan range and optional midpoint partition. Server-only outages are network.server_down; per-endpoint outage ticks use network.endpoint_down. Earlier outage_steps affect the existing simulated links. The default is an intact channel. Example JSON configurations cover delay, loss, duplication, reordering, agent/server disconnection and partitions. Parameters describe software fixtures with no radio calibration.
