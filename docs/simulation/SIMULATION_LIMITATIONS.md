# SIMULATION LIMITATIONS

Grid rules are synthetic software fixtures. Energy, water, smoke, damage, radio propagation and detection confidence lack physical calibration. Random movement of synthetic people has no behavioral interpretation. There is no buried-person inference. Link hooks model delivery without durable replay, authentication or an incident ledger. The simulator runs trusted in-process code. A Python reference to the engine grants developer access to truth. The sparse symbolic observation model is unsuitable for evaluating real imagery.
